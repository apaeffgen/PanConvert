## What is Panconvert

Panconvert is a GUI wrapper for the document converter [pandoc](https://pandoc.org). It just passes the pandoc options from user inputfields to pandoc itself. Pandoc handles the conversion. The official homepage is at [Panconvert-Home](https://panconvert.sourceforge.net).

## How to use Panconvert and Pandoc

It is helpful to have a good understanding of the comand line document converter pandoc. Panconvert uses all the available options of Pandoc. What Pandoc can´t do, Panconvert cannot do as well. If you have doubts, read the Pandoc help. See the links below.

- [Pandoc-Help](https://pandoc.org/MANUAL.html)
- Panconvert detailed help see [the User_Guide Section](User_Guide/Basic_Usage.md)
- Panconvert Installation Guide you will find [here](Developer/Install_Instructions.md)

## Features

* Convert documents via a graphical user interface
* Markdown, Latex, OPML, docx, EPUB …
* All [Pandoc-Formats](https://pandoc.org/MANUAL.html#options) are supported
* Cross-Platform: Linux, MacOS, Windows
* Batch conversion is possible
